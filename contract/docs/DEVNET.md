## IDL for the server

Copy these two files. Both are generated by `anchor build` into `target/`, which is gitignored, so run `anchor build` in `contract/` first on a fresh clone:

- `contract/target/idl/reztor.json` (the IDL JSON)
- `contract/target/types/reztor.ts` (the TypeScript type for `Program<Reztor>`)

`anchor idl fetch 4hAFR3JFKmE5GkJFDSVUHB1LwcsZkQBszCq9kwFu5MHZ --provider.cluster devnet` returns the same JSON from chain.

The reference client is `contract/scripts/lib.ts` (`@anchor-lang/core` 1.1.2, `@solana/web3.js` 1.99.0, `@solana/spl-token` 0.4.15).

## Scripts

Run from `contract/` with `npx tsx scripts/<name>.ts`. `RPC_URL` overrides the default `https://api.devnet.solana.com`.

| Script | Does |
| :---- | :---- |
| `gen-keys.ts` | Creates `scripts/keys/authority.json` and `player-0..3.json`. Never overwrites. |
| `create-mock-mint.ts` | Creates the mock mint once; writes `deployments/devnet.json`. |
| `fund-wallets.ts <pubkey...>` | 0.5 SOL + 240 mock SKR to each, from the deployer. |
| `init-config.ts` | `initialize_config` (skips if it exists), creates the treasury ATA, tops the authority up to 2 SOL. |
| `smoke.ts` | The two matches above, with fresh match IDs each run. Exits non-zero on any mismatch. |

The public devnet RPC rate-limits (HTTP 429). `@solana/web3.js` retries on its own and the smoke run still passed; use a private RPC through `RPC_URL` if it gets worse.
